# Effortless CAD Home Designer

A modern, minimal browser-based CAD planner for professional home layouts with more AutoCAD-like workflows.

## Features
- Room, door, window placement with grid snapping and smart wall anchoring
- Ortho mode (toggle + Shift hold), hand/pan navigation, mousewheel zoom
- Wireframe mode, dark/light theme switch
- Measure tool with auto distance labels
- Text notes, basic shapes, pen/highlighter markup layers
- Layer system (Structure, Openings, Annotation, Markup) with visibility and lock controls
- Selection editing: recolor components, change stroke width, drag, duplicate, delete
- Z-order management (bring front / send back)
- Undo/redo support with keyboard shortcuts (`Ctrl/Cmd+Z`, `Ctrl/Cmd+Y`)
- Export and import project JSON

## Run
Open `index.html` directly in a browser, or serve this folder:

```bash
python3 -m http.server 4173
```
